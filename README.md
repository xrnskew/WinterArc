# Winter Arc

Личный трекер дисциплины для «арок» — периодов работы над собой с датой начала
и конца. Привычки, оценки дня, цели и задачи, аналитика и достижения. Суровая
зима: монохром, ночь, живая метель на фоне.

## Запуск

```
npm install
npm run dev      # http://localhost:5173, витрина дизайн-системы — /kit
npm test         # тесты
npm run build    # сборка в dist/
```
