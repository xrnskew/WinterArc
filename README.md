# Winter Arc

Личный трекер дисциплины для «арок» — периодов работы над собой с датой начала
и конца (по умолчанию 1 октября – 31 декабря). Суровая зима: монохром, ночь,
живая метель на фоне. Интерфейс на русском, сделан сначала для телефона.

## Что умеет

- **Арка** — отсчёт дней, лента зарубок (день = черта, яркость = индекс дисциплины),
  «зачем я это делаю». Прошлые арки уходят в историю, привычки переходят в новую.
- **Привычки** трёх типов: да/нет, количество, время. Расписание: каждый день,
  по дням недели или «N раз в неделю». Серии, статистика, график.
- **Чек-ин** — отметить день за минуту: привычки, оценки 1–10 (энергия, настроение,
  фокус или свои шкалы), заметка.
- **Командный центр** — виджеты на выбор: индекс недели, неделя, сегодня, серия,
  оценка, тепловая карта, цель, задачи, «зачем».
- **Цели** по шагам и числовые (пополнения или замеры) с прогнозом «при таком
  темпе — к …»; **задачи** с приоритетом и сроком. Красным — только просроченное.
- **Аналитика** — календарь арки, индекс по неделям, тепловые карты привычек,
  оценки по неделям, связи: «в дни с тренировкой энергия выше на 1,2».
- **Обзор недели** — автоматические итоги и три вопроса.
- **Ледяные жетоны** за серии, рубежи, идеальные дни, цели и обзоры.
- **PWA**: ставится на главный экран, работает без интернета.

## Данные

Всё хранится только в браузере на этом устройстве (localStorage). В настройках:
«Сохранить копию» (JSON-файл), «Загрузить из файла» (в том числе на первом экране —
для переезда на новый телефон), возврат данных до последней загрузки или удаления.
Формат данных версионирован: старые копии открываются в новых версиях через миграции.

## Установка на Mac

Открой приложение в Chrome или Edge → значок установки в адресной строке
(«Установить Winter Arc»), в Safari — «Файл» → «Добавить в Dock». Приложение
откроется отдельным окном и будет работать без интернета.

## Деплой на Vercel

Vercel → Add New → Project → репозиторий `xrnskew/WinterArc`. Настройки берутся
из `vercel.json` (Vite, `npm run build`, папка `dist`, все адреса отдаются
`index.html`, чтобы работали прямые ссылки вроде `/analytics`). В Settings → Git
укажи Production Branch — `main`.

## Разработка

```
npm install
npm run dev      # http://localhost:5173, витрина дизайн-системы — /kit
npm test         # тесты Vitest
npm run build    # проверка типов + сборка в dist/ (с сервис-воркером PWA)
npm run preview  # посмотреть сборку: http://localhost:4173
npm run lint     # oxlint
npm run format   # Prettier
```

Стек: React 19, Vite, TypeScript, Tailwind CSS 4, Zustand, React Router, date-fns,
Recharts, lucide-react, vite-plugin-pwa. Метель — чистый WebGL-шейдер.
