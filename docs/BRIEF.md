# WINTER ARC — техническое задание

Исходное ТЗ владельца проекта. Решения и уточнения к нему — в [PLAN.md](PLAN.md).

> После утверждения владелец изменил ТЗ: тип привычки «Отказ» (с «Тягой сейчас»,
> срывами и сэкономленными деньгами) убран, красный — только для просроченного.
> Актуальные решения — в PLAN.md, они важнее этого текста.

## Идея

Личный инструмент для «арок» — периодов работы над собой с датой начала и конца
(по умолчанию 1 окт – 31 дек). Ничего не захардкожено: привычки, метрики, цели
и виджеты пользователь создаёт и настраивает сам. Приложение должно мотивировать
каждый день и годами подстраиваться под владельца.

## Стек

- React + Vite + TypeScript, Tailwind CSS, Recharts
- WebGL-шейдер через @react-three/fiber или чистый fragment shader на canvas
  (что легче и быстрее)
- PWA: manifest + service worker, ставится на телефон
- Данные в localStorage + экспорт/импорт JSON
- Модель данных с полем version и миграциями, чтобы обновления приложения
  не ломали старые данные
- В `.claude/settings.json` — плагин `frontend-design@claude-plugins-official`

## Визуальный стиль — главное

Суровая зима. Монохром: чёрный, графит, серый, белый. Никаких цветных градиентов
и сияний. Атмосфера: ночь, метель за окном, тишина и дисциплина.

- Фон: живой шейдер метели — снег идёт в несколько слоёв глубины (крупные хлопья
  близко, мелкие вдали, лёгкий размыв дальних), порывы ветра периодически сносят
  снег вбок, едва заметная позёмка внизу экрана
- Палитра: почти чёрный (#0a0a0a), графит (#1a1a1a), серые оттенки
  (#2a2a2a – #9a9a9a), белый для цифр и акцентов. Единственный цветной акцент —
  приглушённый красный для срывов и просроченного
- Карточки: тёмное матовое стекло (backdrop-blur), чтобы снег мягко просвечивал
  сквозь интерфейс; тонкие серые границы, лёгкая шум-текстура, как у плёнки
- Шрифты: сжатый жёсткий для заголовков (Oswald / Bebas Neue), моноширинный
  для цифр (JetBrains Mono)
- Цифры крупные, белые, как на табло, с анимацией пересчёта
- Микроанимации: прогресс-бары заполняются белым с лёгким свечением, отметка
  привычки — короткая белая вспышка, как отблеск фонаря в метели
- Графики в оттенках серого и белого, без цветных линий
- Производительность: ограничение FPS, пауза шейдера в неактивной вкладке,
  prefers-reduced-motion, на слабых устройствах — статичный тёмный фон с редкими
  CSS-снежинками
- Ползунок в настройках: интенсивность метели (выкл / лёгкий снег / метель / буран)
- Дизайн-токены в одном месте, чтобы позже можно было добавить другие темы
- Mobile-first, интерфейс на русском

## Сущности (всё создаёт пользователь)

### Арка

- Название, даты начала/конца, описание «зачем»
- Можно архивировать и начинать новую арку; история прошлых арок сохраняется

### Привычки — 4 типа

1. Да/нет (сделал или нет)
2. Количество (отжимания, страницы, стаканы воды) с дневной целью
3. Время (минуты: учёба, спорт, практика) с дневной или недельной целью
4. Отказ (от чего-то вредного): серия дней + всего чистых дней за арку; срыв
   не обнуляет общий счётчик, записывается событием с причиной; опционально
   «стоимость в день» → считает сэкономленные деньги; кнопка «ТЯГА СЕЙЧАС» —
   5 минут: таймер и дыхание 4-4-6 с анимацией

У каждой: название, иконка, цвет-акцент, расписание (каждый день / дни недели /
N раз в неделю).

### Оценки дня

Пользователь сам задаёт шкалы 1–10 (по умолчанию: энергия, настроение, фокус)
+ заметка дня.

### Цели

- Название, дедлайн, шаги (чекбоксы), прогресс
- Тип «числовая цель»: текущее/целевое значение с историей пополнений
  (накопления, вес, км и т. д.) и прогнозом «при таком темпе к …»

### Задачи

- Привязка к цели (необязательно), приоритет, дедлайн
- Просроченное подсвечивается красным

## Экраны

1. Командный центр — отсчёт до конца арки, прогресс %, индекс дисциплины недели
   (0–100), виджеты. Виджеты пользователь выбирает и переставляет сам
2. Чек-ин дня — все привычки и оценки на одном экране, заполняется за 30 секунд
3. Привычки — список, у каждой своя страница со статистикой, сериями и графиком
4. Цели и задачи
5. Аналитика — графики привычек и оценок; календарь арки (цвет дня по индексу
   дисциплины); тепловая карта в стиле GitHub для любой привычки; простые
   корреляции словами («в дни, когда X, оценка Y выше в среднем на Z»)
6. Обзор недели — автоматические итоги + поля: что получилось, что нет, фокус
   на следующую неделю
7. Достижения — автоматические бейджи за серии и рубежи (7/30/60/90 дней,
   первые 10 часов и т. д.), в виде ледяных жетонов
8. Настройки — арка, привычки, шкалы, виджеты, экспорт/импорт, сброс
   с подтверждением

## Онбординг

При первом запуске: создать арку и 3–5 привычек из шаблонов (спорт, сон, учёба,
чтение, отказ от …) или своих.

## Порядок работы

1. Сначала структура папок, модель данных (типы TS) и дизайн-система. Ждать «ок».
2. Дальше по этапам, после каждого — коммит:
   а) каркас, навигация, дизайн-система, шейдер-фон
   б) модель данных, арка, онбординг
   в) привычки всех 4 типов + чек-ин
   г) командный центр с виджетами
   д) цели и задачи
   е) аналитика, графики, тепловые карты
   ж) обзор недели + достижения
   з) PWA, настройки, экспорт, полировка
3. Код чистый и читаемый: владелец учит React и будет сам его дорабатывать.
   Понятные названия, без магии, логика отдельно от UI.
